# The Reasoning Gate A protocol for early-career lawyers. The AI stays locked until the junior has done the thinking. Before a model touches the problem, the junior must commit four things on the record: a framing of the issue in their own words, a first instinct, the authority or fact that would settle the question, and the downside risk if they are wrong. Only then does stage five unlock — and stage five is not "copy the answer", it is audit it against their own prior reasoning. A supervisor view shows the full reasoning trail with coaching prompts focused on the gap between instinct and audit, which is where real teaching lives. **The design bet:** the value of a lawyer in an AI era is catching the answer that is confidently wrong. You cannot catch what you were never trained to question. ## Run it Open `index.html` in any browser, or enable GitHub Pages on this repository (Settings → Pages → deploy from `main`) to host it live. No build step, no dependencies, no data leaves the browser — the reasoning trail is stored locally on the user's machine only. Built by [Jean Gan](https://github.com/JGKC-letsgo).
